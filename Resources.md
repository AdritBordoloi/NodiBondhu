## Data used in NodiBondhu

| Data | Source | Access |
|---|---|---|
| Satellite imagery, villages, land use, road routes | Bhuvan, NRSC/ISRO | Imagery is open; APIs need keys |
| Flood radar, July 2026 | Copernicus Sentinel-1 RTC, Microsoft Planetary Computer | No account |
| River flow | GloFAS through Open-Meteo Flood API | No key |
| Rain forecast and past rain | Open-Meteo | No key |
| Elevation | Copernicus DEM GLO-30 | No account |
| Rivers, settlements, boundaries, place names | OpenStreetMap | No account |
| Dikhow level, 24 July 2026 | CWC reading in Morung Express: https://morungexpress.com/assam-flood-disaster-management-authority-issues-warning-for-rising-river-water-level | Public |
| Kushiyara level, 22 July 2026 | ASDMA alert: https://www.facebook.com/sdmaassam/ | Public |

## Useful but not used yet

- CWC flood forecasts: https://ffs.india-water.gov.in/ (automated check did not work; read by hand)
- SMART AXOM water levels: https://smartaxom.nesdr.gov.in/analytics/flood/waterlevelinfo (table came back empty when read automatically)
- NRSC Flood Hazard Zonation Atlas of Assam 1998-2023 (local PDF; yearly figures are charts)
- Bhuvan flood layers: https://bhuvan-ras2.nrsc.gov.in/cgi-bin/flood.exe
- Need a login: Copernicus Data Space, NASA Earthdata, Google Earth Engine. IMD gridded rainfall may need a request
